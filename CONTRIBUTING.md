Contributing

First off, thank you for considering contributing to this project. Whether you're fixing a bug, adding a feature, updating documentation or testing, your help is appreciated.

Ways to Contribute

    You can contribute by:
    
    Fixing bugs
    Adding new systems
    Improving existing code
    Improving documentation
    Cleaning up or refactoring code
    Reporting issues or suggesting ideas

If you're unsure whether something is worth contributing, feel free to ask on the Discord Server.

Before You Start

If you're planning a large addition/change or a feature that significantly changes how something works, it's a good idea to open an issue or discuss it first on the Discord Server.

For smaller fixes, feel free to jump right in.
    
    How to Contribute
    
    Fork the repository.
    Create a new branch for your changes.
    Make your changes.
    Test your code if applicable.
    Submit a Pull Request with a clear description of what you changed and why.
    
    Try to keep pull requests focused on a single change makes them easier to review.

- - -

    Code Style
    
    There isn't a very strict style guide, but please try to follow the handbook. A few good practices are:
    
    Keeping code readable.
    Using meaningful variable and function names.
    Following the existing style used in the project.
    Removing debugging code before submitting.

- - -

    Pull Requests
    
    When opening a PR, please include:
    
    A short description of the changes.
    Why the change was made (if it isn't obvious).
    Any screenshots or examples if they help explain the change.

Constructive feedback is welcome, and revisions may be requested before a PR is merged.
